## 🏃 Local Development

Run the lightweight development server:

```bash
# Clone the repository
git clone https://github.com/ankitkumar2006official-design/portfolio.git
cd portfolio

# Launch local server
node server.js
```

Then visit:
- **Portfolio:** `http://localhost:3000`
- **ATS Resume:** `http://localhost:3000/resume.html`
